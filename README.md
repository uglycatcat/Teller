# 本项目Teller是什么  
  
面向长篇创作者的 AI 原生写作工作台。  
  
## 1. 项目背景  
  
小说/网文创作通常是 20 万到 100 万字的长文本工程。当前常见工作流存在几个问题：  
  
- 通用办公软件（Word/WPS）不针对长篇创作场景设计。  
- 写作、章节管理、设定整理、版本管理分散在多个工具中。  
- AI 辅助写作通常要在浏览器与编辑器间反复切换，破坏创作专注。  
  
Teller 的目标是将上述能力集中到一个工作台中，降低切换成本，提升持续写作效率。  
  
## 2. 产品定位  
  
**一句话定位：** 面向长篇创作者的 AI 原生桌面写作工作台。  
  
**核心价值：**  
  
- 少切换：写作与管理在同一界面完成。  
- 可持续：支持长周期、长篇幅内容生产。  
- 易扩展：为后续 AI 能力预留空间。  
  
## 3. 目标用户  
  
- 网文作者、小说作者、长篇内容创作者。  
- 仅支持 Windows 桌面软件，重视持续产出、稳定保存与专注体验。  
  
## 4. 核心参考目标  
  
- **VS Code / Cursor / Obsidian 是核心参考目标**  
- UI 交互、信息架构与可扩展性优先参考 VS Code  
- 参考仓库：https://github.com/microsoft/vscode.git  
  
## 5. 开发须知  
  
- 该项目为独立开发者与 AI 协作搭建。开发者主要扮演产品经理角色。  
- 使用 Electron 框架  
- 产出形态为桌面应用（不是网页站点）  
- 整体前端、UI 交互、美术设计风格优先对齐 VS Code
