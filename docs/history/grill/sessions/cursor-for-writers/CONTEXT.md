# Teller（本会话工作稿）

面向长篇创作者的 AI 原生桌面写作工作台；本会话将其本质定位为：**专门用于小说/长文写作场景的 Cursor**。

> 本文件仅服务 `docs/grill/sessions/cursor-for-writers/` 会话，合并进根 `CONTEXT.md` 前以本文件为准。本会话增量术语如下；与根 CONTEXT 冲突时，以本会话问答沉淀为准。

## Language

**Agent 模式（本会话增量）**：
显式开启后，AI 可一轮提议修改多个章节/设定等内容，并以变更集预览后接受/拒绝。权限上：允许提议**新建**与**重命名**章节/设定，以及改正文；**不允许**提议删除（删除仍由作者人手操作，进作品垃圾箱）。
_Avoid_：Agent 默认可删章节/设定, 结构变更只能人手连新建也不行, 新建/重命名无预览直接落盘

**AI 上下文裁剪（本会话增量）**：
当默认上下文（写作规则 + 当前章节 + 全部设定，及已 @ 资料）超过模型窗口时，系统智能裁剪：优先保留写作规则与当前章节；设定按相关度或长度截断/摘要。界面须标明各设定的纳入状态（完整 / 截断或摘要 / 未纳入），禁止静默丢弃。
_Avoid_：超限静默截断无提示, 超限直接失败且无裁剪路径作为默认, 为省窗口默认改为不带设定

**AI 会话存储（本会话增量）**：
AI 面板的多条会话历史默认保存在作品目录元数据区（如 `.teller/sessions/`），随作品备份与移动；打开同一作品目录即可恢复会话列表与内容。
_Avoid_：会话仅存应用本机库导致拷贝作品丢失聊天, 强制跨作品的全局聊天墙
