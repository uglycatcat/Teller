# Teller（本会话工作稿：完整产品全量细化）

> 本文件仅服务 `docs/grill/sessions/full-product-refinement/` 会话；合并进根 `CONTEXT.md` 前以本文件为准。本会话增量术语如下；与根 CONTEXT 冲突时，以本会话问答沉淀为准。

## Language

**快照 / 版本管理（本会话重大修订）**：
快照从「简单备份点」升级为**类 git 的版本管理**。显式创建快照 ≈ git commit（可填备注），自动保存不产生版本（仅防丢，ADR 0007 边界不变）；引入 **branch（分支）**：可用于平行剧情试写与动大改前的安全网，支持 checkout 切换分支继续写作。**不提供自动 merge**——分支内容由作者手动取舍（小说文本自动合并冲突率高，此为与 git 的刻意差异）。历史以**树状 DAG 图**可视化（含分支线），并支持快照间 / 快照与当前的文稿 diff。存储采用内容寻址去重（未变文件共享存储），物理仍存作品目录元数据区（如 `.teller/snapshots/`），随作品备份与移动。此条**推翻** ADR 0006/0007/0014/0055 及 CONTEXT 快照定义中的「版本分支 / Git 提交」回避立场。
_Avoid_：仅备份点无分支, 分支只读不可 checkout, 自动文本 merge（冲突体验差）, 无树状历史图看不出分叉, 版本库存应用全局不随作品走

**章节状态（本会话新增）**：
每章一个状态标记，存于该章节文稿首部 YAML frontmatter（如 `status: 定稿`），随文件备份与移动。状态三态：**草稿 / 进行中 / 定稿**。frontmatter 仅承载状态等字段，**不**作为标题权威（标题仍以文件名序号后标题段为准，ADR 0049 不变）。侧栏与标签可用轻量视觉（图标/颜色点）展示状态。
_Avoid_：状态塞进文件名后缀导致标题段解析歧义, 状态存应用全局或集中清单导致与文件脱节, 以 frontmatter 的 title 字段替代文件名标题段权威, 状态值自由标签不收敛

**正文图片与资源目录（本会话新增）**：
章节/设定正文可用 Markdown 本地相对路径引用图片（如 `![](../assets/xxx.png)`）。图片实际存放于作品根下约定资源目录 `assets/`（与 `chapters/`、`settings/` 并列，由 Teller 专用管理）。图片纳入快照与导出副本；`assets/` 资源目录**不进**「其它文件」通用树。外链图片列为后续增强，非首版必达。
_Avoid_：图片散落在 chapters/ 内混入二进制, 图片不进快照/导出副本导致迁移丢图, assets/ 混入其它文件通用树, 外链图片作为首版必达

**AI 用量与模型（本会话细化）**：
AI 面板与内联 AI 每次回复后显示本次输入/输出 token 用量（费用估算为可选增强，非必达）。模型供给 BYOK、DeepSeek 默认（ADR 0008 不变）；应用设置定全局默认模型，每条 AI 会话可临时覆盖切换。
_Avoid_：隐藏 token 用量无可感知成本, 会话内不可换模型只能全局唯一, 每会话强选模型无全局默认

**内联 AI 触发（本会话细化）**：
内联 AI 触发方式为选中文本后浮现「改写/续写」悬浮工具栏（对齐 Cursor）；自定义快捷键（ADR 0034）作为并存入口。
_Avoid_：仅右键菜单触发不可见, 仅快捷键触发无发现性

**写作规则格式（本会话细化）**：
写作规则文稿（`.teller/rules.md`）以自然语言为主，新建时提供模板骨架（人称/文风/禁词/红线等引导小节）供作者参考，可全删。
_Avoid_：强制结构化模板框死个性规则, 纯空白无引导

**编辑器交互（本会话细化）**：
每个编辑器标签有独立撤销/重做栈；标签栏支持拖拽排序；侧栏章节/设定列表顶部提供过滤框实时筛选标题（纯视图、不改扁平模型，不做分组折叠）；分屏通过拖拽标签到左/右/下边缘触发，右键标签「向右/向下拆分」并存。
_Avoid_：跨标签全局撤销栈导致回退不可预期, 标签不可拖拽排序, 侧栏长列表无过滤, 分屏引入分组折叠或仅靠按钮

**章节/设定文件名（本会话细化）**：
章节与设定的文件名数字前缀采用三位（`001`）；排序按数字值解析，超 999 章后位数变化不破坏顺序。
_Avoid_：前缀位数不固定导致字符串排序错乱

**字数统计（本会话细化）**：
字数统计支持两种口径切换：仅汉字，或汉字 + 标点（字符数，对齐网文平台惯例）；统计说明中写清当前口径。
_Avoid_：口径写死不可切换, 不说明统计口径

**文稿 / Markdown 能力（本会话细化）**：
编辑器与预览支持全量 GFM（含表格/任务列表/删除线等）、数学公式与图表（如 Mermaid）。
_Avoid_：仅基础语法无表格任务列表, 把 Word/富文本作为编辑主形态

**frontmatter 字段（本会话细化）**：
章节 frontmatter 支持 `status` 状态字段 + 常用字段（created/updated、字数、标签等）；标题仍以文件名标题段为权威（ADR 0049 不变）。
_Avoid_：frontmatter 的 title 取代文件名标题段权威, 字段无边界任意扩展

**平台与分发（本会话细化）**：
仅发布 Windows（不做 macOS/Linux）；安装包为主形态，更新走作者手动下载覆盖，不引入应用内自动更新。
_Avoid_：承诺 macOS/Linux 完整支持, 应用内自动更新强推
