# 06 编辑器

本文档描述文稿编辑器（章节/设定）的编辑、排版、标签、分屏、查找替换与快捷键能力。

---

## 6.1 Markdown 编辑

- Markdown 源码为权威形态与默认编辑视图；可切换预览、或分屏预览。
- 能力边界：**全量 GFM**（标题、粗斜体、列表、引用、链接、图片、分隔线、代码块、表格、任务列表、删除线等）+ **数学公式**（如 KaTeX）+ **图表**（如 Mermaid）。
- 不做富文本 / Word 式所见即所得为唯一编辑方式。

## 6.2 排版设置

| 项 | 默认 | 可配置 |
|---|---|---|
| 字体家族 | 系统默认 | 可调 |
| 字号 | 系统默认 | 可调 |
| 行高 | 系统默认 | 可调 |
| 最大内容宽度 | 不限 | 可选 |
| 软换行 | **开** | 可关 |
| 行号 | **显示** | 可关 |
| 小地图 | **关** | 可开 |

- 配色随主题。

## 6.3 撤销 / 重做

- 每个编辑器标签持有**独立**撤销/重做栈，切换标签不串。
- 内联 AI 接受后的修改进入正常撤销栈，可撤销回退。

## 6.4 标签管理

- 多标签：同时打开多个章节/设定。
- 标签栏支持拖拽排序。
- 关闭标签：直接关（依赖自动保存），仅保存失败时拦截。

## 6.5 分屏

- 网格分屏：左右 + 上下，形成对照。
- 触发方式：拖拽标签到左/右/下边缘；右键标签「向右/向下拆分」。
- 分屏布局随作品工作区状态一并恢复。

## 6.6 查找与替换

- 当前文稿内：查找 + 替换（交互对齐 VS Code）。
- 作品级：关键词搜索 + 批量替换（带结果预览与确认），默认仅作用于章节与设定，不默认改参考资料。
- 不做语义搜索。

## 6.7 图片引用

- 正文用 Markdown 本地相对路径引用 `assets/` 下的图片（如 `![](../assets/xxx.png)`）。
- 外链图片为后续增强，非首版必达。

## 6.8 专注模式

- 一键隐藏侧栏等 chrome，正文居中版心显示，可退出。

## 6.9 快捷键

- 为常用操作提供 Windows 优先的默认快捷键（强制保存、查找替换、新建章节、专注模式、内联 AI 等）。
- 在应用设置中可查看与修改键位。

## 6.10 自动保存

- 文稿短间隔自动落盘，并在失焦或切换标签时保存。
- 状态栏轻量指示保存状态（「未保存」圆点/「已保存」），无 Toast。
