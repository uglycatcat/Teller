# 09 搜索、统计与导出

本文档描述作品搜索、字数统计与导出能力。

---

## 9.1 作品搜索

- 在当前作品范围内按关键词检索并定位匹配处；**关键词全文搜索**，不做语义搜索。
- 默认搜索范围：`chapters/` + `settings/`；可勾选将「其它文件」中可检索文本纳入搜索。
- 查找/替换交互对齐 VS Code：
  - 当前文稿内：查找 + 替换。
  - 作品级批量替换：默认仅作用于章节与设定，带结果预览与确认，避免误改参考资料。

## 9.2 字数统计

- 状态栏常显当前打开文稿的字数。
- 经「作品 → 统计」或状态栏入口查看各章节字数与作品合计。
- 计量口径**可切换**：仅汉字，或汉字 + 标点（字符数，对齐网文平台惯例）；统计说明中写清当前口径。
- 侧栏章节标题旁**不**常驻实时字数。

## 9.3 导出

| 类型 | 行为 |
|---|---|
| 单文稿 | 当前章节/设定导出为 Markdown 或纯文本 |
| 整书合并 | 按章节顺序合并为一个 Markdown/纯文本；每章以标题开头、章间空行；设定可勾选是否并入；参考资料不塞进合并文件 |
| 文件夹副本 | 含 chapters、settings 与同级资料；默认排除快照库（避免体积膨胀） |

- 完整形态**不含** Word/PDF 排版导出或平台一键发布。
