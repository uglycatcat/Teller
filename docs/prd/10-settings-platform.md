# 10 设置、平台与隐私

本文档描述应用设置、主题、平台/分发与隐私数据策略。

---

## 10.1 应用设置

统一配置页，收入：

- 主题（深色/浅色/跟随系统）
- 垃圾箱保留期（7 / 30 / 90 天 / 永不自动清除）
- 编辑器排版（字体家族、字号、行高、最大宽度、软换行、行号、小地图）
- AI API Key 配置（+ 全局默认模型）
- 快捷键查看与修改
- 检查更新入口

约束：

- API Key 存于本机安全存储（系统密钥链/加密存储），不写入作品目录明文文件。
- 界面文案简体中文唯一完整支持。
- 快捷键有默认方案，可查看与修改。

## 10.2 主题

- 默认深色；可切浅色；可跟随操作系统。

## 10.3 平台与分发

- 技术框架：Electron。
- 平台：**仅 Windows**（不做 macOS / Linux）。
- 分发：Windows 安装包。
- 更新：作者手动下载新版覆盖，不引入应用内自动更新机制。

## 10.4 隐私与数据

- **默认不采集遥测**。
- 作品正文与 API Key 不上传到 Teller 自有服务器；AI 请求仅发往作者配置的模型供应商。
- 完整形态不要求账号或云同步。
- 理想形态不引入 MCP 或通用外部工具协议，不依赖外挂工具生态。
- 若未来增加匿名统计：须默认关闭、可开关，且不得包含文稿内容。
