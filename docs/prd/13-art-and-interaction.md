# 13 美术与交互设计

本文档定义 Teller 的视觉语言与交互细节（Q96–Q111 拍板）。核心原则：**结构对齐 VS Code，视觉服务写作**——功能交互沿用 Cursor/VS Code 心智，但视觉层刻意更柔和、低对比、偏暖，适配长时间阅读与写作。

---

## 13.1 视觉基调

| 项 | 决策 |
|---|---|
| 整体风格 | VS Code 结构 + 写作视觉（柔和、低对比、偏暖） |
| 品牌主色 accent | **琥珀 / 橙** |
| 深色背景 | **暖深灰**（与琥珀统一色调，降低冷工具感） |
| 圆角 | 中等（6–8px），柔和不松散 |
| 密度 / 间距 | 舒适（适中留白），长文场景甜点 |

- 主题：深色默认，可浅色、可跟随系统（ADR 0018 不变）。
- 不照搬代码 IDE 的高对比、紧凑密度视觉。

## 13.2 字体

| 场景 | 决策 |
|---|---|
| UI 界面 | 系统默认（**微软雅黑**，仅 Windows 下最省事） |
| 编辑器正文 | 默认**衬线（宋体类）**，设置里可切换黑体 |
| UI 与正文 | 字体分离，各自可调 |

- Markdown 源码语法高亮：**柔和低对比**——标题/粗体弱高亮，语法符号（`#`、`**`）不刺眼；保留结构辨识、不抢正文。这是「写作工具 vs 代码编辑器」的关键差异。

## 13.3 布局

- 侧栏 / AI 面板边界**可拖拽调整**（对齐 VS Code），配合专注模式可快速收起。
- 三栏布局与网格分屏见 `04-workbench.md`、`06-editor.md`。

## 13.4 动效与反馈

| 项 | 决策 |
|---|---|
| 动效策略 | 轻量缓动，关键过渡 100–200ms（面板展开、分屏、标签切换），不炫技 |
| AI 流式输出 | 流式 + 尾部脉冲/闪烁光标（提示「还在生成」） |
| 空状态 | 引导文案 + 行动按钮（如「点击 + 新建第一章」） |
| 自动保存指示 | 圆点：灰=已保存，琥珀=未保存/保存中 |

## 13.5 特定界面

| 界面 | 视觉 |
|---|---|
| 欢迎页 | 极简 + 轻品牌氛围（logo + 琥珀点缀），有第一印象不喧宾夺主 |
| 内联 AI 悬浮工具栏 | 跟随选区的小工具条（Cursor 式），触发即见 |
| 专注模式 | 隐藏侧栏/AI 面板 + **渐隐过渡**（独立配色作后续增强） |

---

## 规避清单（_Avoid_）

- 照搬代码 IDE 的高对比/紧凑/冷色视觉
- 动效炫技（弹性、渐变、毛玻璃堆砌）打断写作
- 流式输出无「生成中」指示、或整段生成完才显示
- 空状态纯空白无引导
- 保存状态无任何指示，或频繁 Toast 打扰
- Markdown 语法符号高对比着色（偏代码感）
- 欢迎页零品牌感或过度装饰
- 专注模式进出生硬跳变
