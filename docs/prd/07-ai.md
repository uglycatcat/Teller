# 07 AI 能力

本文档描述 Teller 的全部 AI 能力——这是产品的灵魂。总原则先行，再逐项细化。

---

## 7.1 总原则

**AI 与工作区之间的交互整体对齐 Cursor**（面板、内联、流式、接受/拒绝、插入/应用、附加上下文、Ask/Agent 切换等）。除非本文档或 ADR 明文写出例外，否则此类交互细节默认按 Cursor 行为解释。

---

## 7.2 AI 面板（AI Panel）

- 与编辑器并排的对话式 AI 区域，围绕当前作品提问、续写、改稿。
- 默认上下文：**当前章节 + 该作品全部设定**（+ 写作规则）。
- 可 `@`/附加其它章节及「其它文件」中可抽取文本的资料（仿 Cursor）；不默认塞入整个 `reference/`。
- 多条会话：新建 / 切换 / 归档 / 删除；重开作品回到先前会话列表与内容。
- 流式输出；回复可「插入到光标处」或「应用到选区」（大块变更可预览确认）。
- 显示本次输入/输出 token 用量。

## 7.3 内联 AI（Inline AI）

- 选中正文后就地改写/续写，与面板互补。
- 触发：选中文本后浮现「改写/续写」悬浮工具栏（对齐 Cursor）；自定义快捷键并存。
- 改稿先以预览/对比呈现，接受/拒绝后写入文稿；接受进入撤销栈。
- 流式生成；可取消；失败给可读错误 + 重试/去设置引导，不阻断写作。
- 默认只改当前文稿；跨文稿批量改写须切 Agent 模式。

## 7.4 Ask / Agent 模式

- AI 面板手动切换（对齐 Cursor 的 Ask/Agent）。
- **Ask**：偏问答与单目标协助，不默认批量改写多文稿。
- **Agent**：允许一轮提议修改多个章节/设定及已附加资料，以变更集预览后全部或逐条接受/拒绝。
  - 可提议**新建 / 重命名**章节/设定，以及改正文。
  - **不得**提议删除（删除仍由作者手动操作，进作品垃圾箱）。
- 界面清晰显示当前模式。

## 7.5 上下文模型

- 默认上下文：写作规则 + 当前章节 + 全部设定。
- 可显式追加：其它章节、可抽文本的「其它文件」资料（PDF/Word/Excel/文本）。
- 整部作品其余章节不默认注入；不默认把整个 `reference/` 塞入。
- 图片默认不作为正文上下文（除非后续按 Cursor 能力扩展）。

## 7.6 上下文超限的智能裁剪

当默认上下文超过模型窗口时：

- 优先保留：写作规则 + 当前章节。
- 设定按相关度或长度截断/摘要。
- UI 必须标明各设定的纳入状态：完整 / 截断或摘要 / 未纳入，**禁止静默丢弃**。
- 不把「超限即硬失败、只能手动精选」作为唯一默认路径，也不为省窗口而默认改为不带设定。

## 7.7 写作规则（Writing Rules）

- 存 `.teller/rules.md`，随作品备份与移动。
- 自然语言为主，新建时提供模板骨架（人称/文风/禁词/红线等引导小节），可全删。
- AI 面板、内联、Agent 模式**默认注入**；作者可编辑，可在单次对话中临时关闭应用规则。

## 7.8 写作审阅（Writing Review）

- 内置技能，手动触发（类比 Cursor 的 review）。
- 结果作为**当前会话消息**返回（可疑点、依据等），不用独立审阅面板。
- 不自动改文；作者在对话中决定：仅参考 / 导出审阅 Markdown / 让 AI（可含 Agent）按意见修改。
- 不在保存时后台自动扫描。

## 7.9 内置写作技能（理想形态）

手动触发的一等技能（结果进当前对话消息），至少包括：

| 类别 | 技能 |
|---|---|
| 硬技能 | 写作审阅；续写本章；改写选区/段落；根据本章草稿更新设定（提议修改，预览后接受） |
| 策划向 | 开大纲/拆章建议；情节节拍检查等 |

- 策划向输出是建议文本，不把大纲/细纲提升为一等结构。
- 是否导出 md、是否据此改稿由作者决定。

## 7.10 作品技能（Work Skills）

- 存 `.teller/skills/`，随作品备份与移动。
- 作者可手写，也可在对话中指挥 AI 生成/修改当前作品的 skill。
- 落盘后可与内置技能一样被点名触发，结果进当前会话消息。

## 7.11 技能唤起（`/` 菜单）

- AI 面板输入 `/` 打开技能菜单，列出内置技能 + 本作品技能，选中后当前会话执行。

## 7.12 模型供给

- **BYOK**：作者配置自己的 API Key。
- 默认供应商/模型：**DeepSeek**（Demo/首版先只接 DeepSeek，后续扩展兼容供应商）。
- 应用设置定全局默认模型；每条 AI 会话可临时覆盖切换。

## 7.13 token 用量显示

- AI 面板与内联每次回复后显示本次输入/输出 token 用量。
- 费用估算依赖定价表，列为可选/后续增强。

## 7.14 AI 错误处理

- 无 Key / Key 无效 / 网络失败 / 额度用尽时：显示可读错误 + 去设置配 Key / 重试等引导。
- 进行中的请求可取消。
- AI 失败**不阻断**章节/设定写作与自动保存等核心路径。

## 7.15 无 Key 也能写作

- 打开作品、编辑章节/设定、自动保存、快照、导出等均不依赖 AI。
- API Key 只解锁 AI 面板与内联 AI，不作为进入工作区的前提。
