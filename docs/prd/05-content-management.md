# 05 内容管理

本文档描述作品内各类内容（作品、章节、设定、其它文件、资源）的增删改查与组织规则。

---

## 5.1 作品管理

| 操作 | 行为 |
|---|---|
| 新建 | 欢迎页收集「标题 + 保存位置」，生成约定空目录（`chapters/`、`settings/`、`.teller/`），不预置任何文件 |
| 打开 | 打开作品目录；非作品文件夹询问是否初始化（写入约定结构再打开） |
| 关闭 | 「作品 → 关闭作品」回欢迎页；依赖自动保存，保存失败才拦截 |
| 重命名 | 改显示标题（存 `.teller/work.json`），可选同步文件夹名；文件夹改名失败则保留新标题并提示 |
| 定位 | 在系统资源管理器中显示作品根目录 / 当前文件（Reveal） |

- 作品显示标题可与文件夹名不同；缺失时回退文件夹名。
- 最近打开列表随标题/路径更新。

---

## 5.2 章节管理

| 操作 | 行为 |
|---|---|
| 新建 | 侧栏「+」只填标题 → 生成 `NNN-标题.md`（三位数字前缀），预填较完整模板（一级标题 + 分隔 + 写作提示），可改可删；模板作品级可自定义 |
| 排序 | 侧栏拖拽重排，应用改写数字前缀（按数值解析排序） |
| 重命名 | 侧栏慢双击/右键重命名，只改标题段并更新文件名、保留序号前缀，标签标题同步 |
| 删除 | 进入作品垃圾箱（非系统回收站），可恢复，到期自动清除 |
| 状态 | frontmatter `status`：草稿 / 进行中 / 定稿 |
| 标题 | 显示标题以文件名标题段为准；同类型内唯一，冲突自动加后缀 |

---

## 5.3 设定管理

与章节同一套操作模型：

| 操作 | 行为 |
|---|---|
| 新建 | 只填标题 → `NNN-标题.md`，预填设定向模板（标题 + 别名/外形/性格等资料卡小节），可改可删 |
| 排序 | 拖拽重排，改写数字前缀落盘 |
| 重命名 | 同章节 |
| 删除 | 进入作品垃圾箱 |

- 设定与章节**不互转**；分类错误需删除后按正确类型重建（或从其它文件升格到正确类型）。

### 新建模板（作品级）

- 每部作品可有自己的章节模板与设定模板文稿，存 `.teller/templates/chapter.md`、`setting.md`。
- 新建时优先用作品模板，缺省回退内置模板。
- 不做应用级全局模板编辑。

---

## 5.4 其它文件管理

- 通用文件树（交互参考 VS Code 资源管理器）：
  - 树内新建文件夹/文件；外部创建后目录监视刷新。
  - 删除 → **系统回收站**（不进作品垃圾箱）。
- 打开行为：
  - 常见图片 → 应用内预览。
  - 常规文本（md/txt/json 等）→ 编辑器可编辑。
  - PDF / Word（doc/docx）/ Excel → 阅读/预览（非完整办公编辑）。
  - 未知类型 → 交系统默认程序或提示无法预览。
- **升格**：可将适用文本「移动到章节/设定」，写入对应目录并生成序号文件名，原位置移除。
- **不提供降格**（章节/设定移回其它文件）：需删除后在其它文件中另行创建。

---

## 5.5 资源目录（assets/）管理

- 正文图片存作品根下 `assets/`，用 Markdown 本地相对路径引用（`![](../assets/xxx.png)`）。
- 由 Teller 专用管理，不进「其它文件」树。
- 图片纳入快照与导出副本。

---

## 5.6 垃圾箱

- 入口：仅菜单「作品 → 垃圾箱」（侧栏无入口）。
- 操作：恢复 / 立即永久删除 / 清空。
- 保留期：默认 30 天，可配 7 / 30 / 90 / 永不自动清除。
- 仅章节/设定进入；其它文件删除走系统回收站。

---

## 5.7 外部变更监视

- 监视当前作品目录。
- 无未保存冲突 → 自动加载磁盘版本。
- 有冲突 → 提示选择保留应用内编辑或加载磁盘版本，不静默强载。
