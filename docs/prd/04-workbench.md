# 04 工作区与界面

本文档描述 Teller 的界面结构与交互布局：三栏工作区、资源侧栏、编辑器区、AI 面板、状态栏、欢迎页、窗口管理与专注模式。

---

## 4.1 三栏布局

主工作区固定三栏：

| 位置 | 区域 | 内容 |
|---|---|---|
| 左 | 资源侧栏 | 「章节」「设定」上下可折叠分区 + 「其它文件」树 |
| 中 | 编辑器区 | 多标签编辑器，支持网格分屏 |
| 右 | AI 面板 | 可折叠的对话式 AI 区域 |

UI 交互、信息架构与可扩展性优先参考 VS Code。

---

## 4.2 左侧资源侧栏

### 章节 / 设定分区

- 两个**上下叠放的可折叠分区**（不是顶部分段一次只显示一类）。
- 共用同一套操作模型：按标题新建（`+`）、拖拽排序、重命名、删除进垃圾箱。
- 侧栏顶部提供**过滤框**，实时筛选标题（纯视图，不做分组折叠）。
- 章节标题旁可用轻量视觉展示状态（草稿/进行中/定稿）。

### 其它文件树

- 通用文件树管理根目录自建同级目录（如 `reference/`）与松散文件。
- 支持树内新建文件夹/文件（交互参考 VS Code 资源管理器），外部创建后经目录监视刷新。
- `chapters/`、`settings/`、`assets/`、`.teller/` 不作为「其它文件」主展示对象。

---

## 4.3 中间编辑器区

- 多标签：可同时打开多个章节/设定。
- 网格分屏：左右 + 上下分屏，形成对照；通过拖拽标签到左/右/下边缘触发，右键标签「向右/向下拆分」并存。
- 标签栏支持拖拽排序。
- 每个标签持有**独立**撤销/重做栈。
- 关闭标签：直接关（依赖自动保存），仅保存失败时拦截。
- 文稿默认 Markdown 源码编辑，可切预览或分屏预览。

---

## 4.4 右侧 AI 面板

- 可折叠；与编辑器并排。
- 输入 `/` 打开技能菜单（内置 + 作品技能）。
- Ask / Agent 模式切换（清晰显示当前模式）。
- 多条会话（新建/切换/归档/删除）。
- 流式输出；回复可「插入到光标处」或「应用到选区」；显示 token 用量。

---

## 4.5 状态栏

- 常显当前打开文稿的字数。
- 轻量保存状态指示（「未保存」圆点/「已保存」），无 Toast。
- 可经状态栏入口查看作品字数合计。

---

## 4.6 欢迎页

未打开作品时的起始界面：

- 新建作品（收集标题 + 保存位置）。
- 打开作品目录。
- 最近打开列表（约 10 部，可固定/移除，失效路径可重新定位或移除）。
- 可选的 API Key 快捷入口（跳设置对应项，不强制）。
- 不支持拖入文件夹打开。

---

## 4.7 窗口管理

- 一窗一部作品；多窗口并行编辑**不同**作品。
- 同一作品目录二次打开 → 拒绝第二窗并聚焦已有窗口。
- 「作品 → 关闭作品」回到欢迎页（对齐 VS Code 关闭文件夹）。
- 重开作品恢复：标签集合、激活标签、侧栏折叠、分屏布局、AI 面板开闭。

---

## 4.8 专注模式

- 一键弱化工作台 chrome：隐藏侧栏等非编辑区域，正文居中版心显示。
- 可退出回到完整三栏工作区。

---

## 4.9 界面语言与主题

- 界面语言：简体中文（唯一完整支持）。
- 主题：深色默认，可浅色，可跟随系统。
