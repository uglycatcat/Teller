# 作品根目录：chapters/、settings/，可自建同级目录；其它文件树管同级资料

作品根目录约定：

- `chapters/` — 章节文稿  
- `settings/` — 设定文稿  
- 作者可自建同级目录（例如 `reference/`）存放参考资料等  
- `.teller/` — 元数据与快照等（默认不作为普通创作区打扰展示）

侧栏「章节」「设定」仍是写作主入口（专用列表 + 文件名序号规则）。「其它文件」树用于管理根目录下自建的同级目录与松散文件，不把其中的 `.md` 自动并入章节列表。

「其它文件」树不把 `chapters/`、`settings/` 当作主展示对象（避免与专用列表重复）；需要时仍可通过「在资源管理器中显示」到达磁盘位置。
