## Q1 — Agent 模式对文件结构的权限

**问题：** 显式 Agent 模式下，AI 除了改已有文稿内容，还能否提议**新建 / 删除 / 重命名**章节或设定？

| 选项 | 含义 |
|---|---|
| A. 可以：新建、重命名、删除（进垃圾箱）+ 改正文；一律变更集预览后接受 | 最接近 Cursor Agent 管仓库的能力 |
| B. 可以新建与重命名；**不能**删除 | 扩结构安全；删结构仍人手 |
| C. 只能改已有文件正文；结构变更（新建/删/改名）一律人手 | 最保守；Agent = 多文件改稿器 |
| D. 其他 | （请描述） |

**推荐：** B。长篇 Agent 常要「加一章」「拆设定卡」；删文件误接受代价高，应留给人手或侧栏。

**用户回答：** B

**沉淀：** Agent 模式可提议**新建**与**重命名**章节/设定（及改正文），变更集预览后接受；**不可**提议删除。删除仍由作者在侧栏/菜单完成（进作品垃圾箱）。

**落盘：** 本会话 `CONTEXT.md`「Agent 模式」；`adr/0001-agent-may-create-rename-not-delete.md`

## Q2 — 默认上下文撑爆模型窗口时怎么办

**背景：** 根文档已定默认上下文 =「当前章节 + 全部设定」+ 可 @ 追加。长篇设定往往上万字，加上当前章与规则，很容易超出模型上下文上限——这一点尚未拍板。

**问题：** 当「当前章 + 全部设定 + 写作规则（及已 @ 资料）」超过模型窗口时，产品默认怎么处理？

| 选项 | 含义 |
|---|---|
| A. 智能裁剪 | 优先保规则 + 当前章；设定按相关度/长度截断或摘要，并在 UI 标明「哪些设定被截掉」 |
| B. 硬失败并引导 | 不自动截断；提示超限，让作者手动取消勾选/改用 @ 精选设定 |
| C. 分层默认 | 平时只带「当前章 + 写作规则 + 用户置顶/最近用过的设定」；「全部设定」改为显式开关 |
| D. 其他 | （请描述） |

**推荐：** A。保住「设定默认在场」的产品承诺，同时必须可见地告知裁剪结果，避免 silently 丢设定导致前后矛盾。

**用户回答：** A

**沉淀：** 超限时默认**智能裁剪**：优先保留写作规则与当前章节；设定按相关度/长度截断或摘要。UI 必须标明哪些设定被完整带入、哪些被截断/摘要/未纳入，禁止静默丢弃。

**落盘：** 本会话 `CONTEXT.md`「AI 上下文裁剪」；`adr/0002-smart-context-truncation-with-visibility.md`

## Q3 — AI 会话历史存在哪里

**背景：** 已定「按作品多条会话、可恢复」。未定：会话内容落在**作品目录**还是**应用本机数据**。这影响拷贝作品是否带走聊天、以及对话里可能含未定稿剧情的隐私边界。

**问题：** AI 面板会话（消息历史）默认存在哪？

| 选项 | 含义 |
|---|---|
| A. 作品目录元数据区（如 `.teller/sessions/`） | 拷贝/备份作品文件夹即带走全部会话；换机打开同目录可续聊 |
| B. 应用本机数据（按作品路径索引） | 作品目录更干净；拷贝文件夹不带聊天；换机会话不自动跟走 |
| C. 默认本机；可选「将会话导出/嵌入作品目录」 | 默认隐私；需要带走时再显式打包 |
| D. 其他 | （请描述） |

**推荐：** A。与快照、写作规则同属「作品随身状态」；本地优先下「文件夹即作品」应包含协作上下文。敏感则靠作者不把含机密对话的目录乱传，而不是默认拆开。

**用户回答：** A

**沉淀：** AI 面板会话历史默认存放在**作品目录元数据区**（如 `.teller/sessions/`），随作品文件夹备份与移动；换机打开同一目录可续聊。不默认只存在应用本机库。

**落盘：** 本会话 `CONTEXT.md`「AI 会话存储」；`adr/0003-ai-sessions-in-work-folder.md`

## Q4 — 新建章节/设定的模板能否自定义

**背景：** 已定新建章节/设定会预填内置模板；未定作者能否改「以后新建用什么模板」。

**问题：** 完整形态下，新建模板的定制程度？

| 选项 | 含义 |
|---|---|
| A. 可自定义 | 应用或作品级可编辑「章节模板」「设定模板」；新建时用作者版 |
| B. 仅作品级 | 每部作品可有自己的模板文稿；应用无全局模板编辑 |
| C. 不可自定义 | 只用产品内置模板；作者新建后自行改删正文即可 |
| D. 其他 | （请描述） |

**推荐：** B。不同书的资料卡字段差很大，作品级模板跟目录走更贴「文件夹即作品」；全局模板容易变成第二套设置噪音。
